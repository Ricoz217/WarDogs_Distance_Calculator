# 拟合阻力弹道实验

本实验分支以 WARDOGS Artillery Calculator 的 SPH-2 数值高度模型替换原有真空抛体假设。上游仓库：

<https://github.com/apollyon-sys/wardogs-calculator>

移植基于上游提交 `f43183c0747afa3dc33ec9af93a153a53766bf7f` 中的
`js/workers/terrain-height-solver.js`，依照其 MIT License 使用并改写为 C++20。

模型不是游戏原生常量。它包含分别拟合的低射、高抛有效模型族，使用随速度变化的阻力系数和 RK4 数值积分；全量模型用于生成校准所需的有效发射方向，多组全量/交叉验证模型的 MIL 中位数用于最终高度修正。

平地距离—MIL 射表仍是基准。高差为零时不改变原射表；数值模型只估计高差带来的 MIL 改变量。平台旋转修正按 `1 mil = 0.001 rad` 将有效发射方向的局部角度变化转换回瞄具分划。

使用 v1.4.0 发布版日志回放第二轮校准时，目标水平距离约 `1751.10 m`、高差 `+330.35 m`：

- 原真空高度模型首发解：约 `1040.24 mil`
- 拟合阻力模型首发解：约 `1072.74 mil`
- 实测持续校准收敛：约 `1068.61～1070.23 mil`

第一轮日志仍存在无法由同一刚体平台旋转完全解释的误差，说明车辆姿态、人工输入和模型外因素仍然存在。本分支用于实测比较，不应据此把拟合参数解释为真实炮口初速、真实重力或游戏内部阻力常量。
